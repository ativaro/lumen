# Desktop search

Open **Lumen Search** from the application menu, the topbar or your configured shortcut. The terminal command is `lumen-search`.

| What you have | What to do |
| --- | --- |
| Part of an application name | Type the name, select the application and press Enter. |
| Part of a filename | Type it in Search and choose the file result. To narrow the search to a folder, open that folder in Files and press Ctrl+F. |
| Words from inside a file | Open the folder in Files and press Ctrl+Shift+F. Review the excerpt and open the matching file. |
| A question | Send it from the conversation field. Continue in the same conversation to keep its context. |
| A previous exchange | Reopen its conversation from the history. Restoring a saved draft lets you review it before sending. |

Application and filename searches run locally. Questions and dictation sent as prompts use your configured model. If voice input is unavailable, return to the speech step in Setup.
