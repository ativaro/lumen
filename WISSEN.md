# Personal memory

Use memory when you want Lumen to remember a preference, decision or confirmed solution in later conversations. Open the memory controls in your personal Lumen settings. The direct command is `lumen-wissen --area lumen`.

| Control | What it changes |
| --- | --- |
| Use memory | Allows relevant saved entries to be included in later conversations. |
| Learn from conversations | Allows Lumen to propose new entries from what you said. |
| Automatically accept suggestions | Allows eligible suggestions to be stored without reviewing each one first. Leave this off to review proposals yourself. |

For example, tell Lumen which language you prefer for explanations. If you enabled learning, check the proposed wording and its source. Correct it, accept it or discard it. Review saved entries from the same memory settings and forget anything you no longer want recalled.

Entries are stored locally. The learning step uses the configured model, which can be remote. Forgetting an entry removes it from future local recall. Previous messages, independent backups and content already sent to a provider have their own retention. A remembered solution never authorizes a new action.
