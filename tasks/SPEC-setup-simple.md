# Recommended setup path

Offer a calm, native five-step setup: Welcome, AI, Voice, Desktop, Ready.
The normal route works without choosing technical components. Existing settings
are retained; missing assistant, previews and network tools are recommended.
The primary action installs the displayed selection and advances only on success.
Skipping and retrying remain possible. Optional components, model selection and
speech tuning stay available through expandable customization.

The final page explains the current personality and memory state. Personality
uses the shared editor; memory stays unchanged unless explicitly selected.
Downloads, desktop replacement and provider credentials require their existing
explicit actions. No automatic provider test sends data. Closing a running
installation remains blocked. All text is translated to English.

Verify first run, existing configuration, customized selection, failed/cancelled
install, navigation, memory opt-in/conflict and DE/EN native rendering. No change
to bootstrap prerequisites, support policy or permission defaults.
