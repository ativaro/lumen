# Use a selection in another app

Start with the item you want to work on. Right-click a file in **Lumen Files**, or select a passage in **Lumen Reader**. The available actions depend on the selection.

| You want to… | Choose | What happens next |
| --- | --- | --- |
| Read and annotate a document | Open with → Lumen Reader | Reader imports a reading copy. Highlights and bookmarks belong to that copy. |
| Rewrite or translate a passage | Lumen Compose | Review the selected text, choose a mode, then compare the result before copying it. |
| Keep a receipt with a household record | Add to Lumen Digital Household | Review the proposed document and record before saving. |
| Ask about the selected material | Open with Lumen | Check the context and send a question to your configured model. |
| Discuss a desktop notification | Discuss with Lumen in the notification view | Edit the conversation draft before sending. |

For an ordinary file association, use **Open with** in Files and choose an installed app. [Lumen Files](../../files/README.md) · [Guide index](../README.md)
