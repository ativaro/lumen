# Lumen Halo

The approved mobile Halo mark is shared by Desktop and Server. The graphite tile is used for launchers, the transparent ring for headers and panels. App-specific icons remain distinct.

`lumen.svg` and `lumen-mark.svg` embed raster images for compatibility with the existing icon installation paths. The panel loads `lumen-halo.png` beside its QML component. Both the user installer and Arch package ship these assets.

Source artwork: Lumen Mobile `Assets/AppIcon.png` (approved proposal 1). The transparent version was generated by removing the graphite background while preserving the mint/teal ring, upper-right opening, and orientation. No fonts or third-party logo assets were added.

## Halo-Funktionsfamilie (2026-10-11)

23 aus den freigegebenen Übersichten exportierte Funktionsicons ergänzen das unveränderte Lumen-Hauptlogo. Rasterauflösung 256 px; Desktop-SVGs betten die identischen PNGs mit transparenten Kachelecken ein. Keine Vektororiginale. App-Karten verwenden 40 px (Desktop), 56/72 px (Server), Panel-Menüs 32 px. Sehr kleine 16-px-Icons zeigen vor allem den Halo; Funktionsnamen bleiben deshalb sichtbar.

Desktop: App-Übersicht, Search-Iconprovider ohne Einfärbung, Panel-Appmenü und Launcher. Installer und Arch-Paket kopieren die komplette Icon-Familie. Server: AppCatalog, Suche/Einstellungen/Notification in der Kopfzeile und Drive-Markierung. Symbole für allgemeine Aktionen bleiben unverändert.
