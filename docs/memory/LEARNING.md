# How learning selects memories

With memory and conversation learning enabled, Lumen can propose up to three durable facts, preferences, decisions or confirmed solutions after an exchange. Each suggestion needs a direct quote from the user's current statement. A successful tool result alone cannot establish that a solution worked for you.

Review a suggestion against its source. A passing remark or a quoted document can be misunderstood. You can change its wording, decline it or later forget the saved entry. Automatic acceptance is a separate choice. Lumen checks the current permission and existing edits before saving.

Learning uses a separate, limited session with the selected model. If you select a remote provider it may receive the learning context. In local-only mode the learning path checks for an approved local provider on a loopback address. A failed learning attempt leaves the original conversation answer available.
